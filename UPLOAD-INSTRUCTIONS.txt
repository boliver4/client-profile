CLIENT INFORMATION SHEET v5.3 — RESTORED NO-CACHE BUILD

This package restores the last known working v5.3 application and disables the service worker to prevent an old cached PNG from being served as the homepage.

UPLOAD TO GITHUB
1. Wait until Vercel's deployment rate limit has expired.
2. Delete the existing repository files.
3. Upload the CONTENTS of this folder directly to the repository root.
4. GitHub should show index.html at about 90 KB, manifest.webmanifest, vercel.json, README.txt, and the icons folder.
5. Do not rename an icon file to index.html.
6. Wait for the Vercel deployment to show Ready.
7. Open https://clientprofile.vercel.app/?restore=final in an incognito window.

The home-screen icon remains available through the Apple touch icon and web manifest. Offline caching is intentionally disabled in this recovery build.
